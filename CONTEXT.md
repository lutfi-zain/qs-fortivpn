# FortiVPN Glossary

## Privileged Controller

The root-owned program that owns FortiVPN configuration, lifecycle operations,
and non-secret readiness reporting.

## Controller Interface Version

The compatibility contract between the plugin or installed CLI and the
Privileged Controller. It is independent of release versions.

## Configuration State

A non-secret readiness classification for FortiVPN configuration: missing,
incomplete, ready, or invalid.
